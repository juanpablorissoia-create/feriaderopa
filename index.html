Para una venta única de ropa (tipo feria americana o garage sale de prendas únicas), la mejor opción es WhatsApp con transferencia (Alias) por dos motivos clave: 1. Comisiones: Mercado Pago te cobra entre 3,5% y 6,5% + IVA por cada "Link de Pago". Por transferencia directa (CBU / Alias de Mercado Pago) la comisión es 0%. 2. Control de stock: Como cada prenda suele ser única (hay 1 sola unidad de cada talle), si dos personas abren el link de Mercado Pago al mismo tiempo pueden pagarte la misma prenda las dos. Por WhatsApp, tu amigo habla directamente, le pasan el comprobante, y listo. A continuación tenés el código completo en un solo archivo (index.html). El diseño es minimalista, moderno (estilo streetwear/tienda minimal) y 100% pensado para celular, que es desde donde van a entrar desde Instagram. Código: index.html Creá un archivo llamado index.html y pegá exactamente esto: Catálogo
¿Cómo lo configurás y qué necesitás? Solo tenés que definir dos cosas dentro de ese archivo: 1. El teléfono: En la línea const TELEFONO_WHATSAPP = "54911XXXXXXXX"; poné el número de tu amigo (con el 549 si es de Argentina). 2. Las fotos y prendas: - Creá una carpeta llamada fotos al lado del index.html. - Poné las fotos ahí (ej: nike-af1.jpg, buzo-negro.jpg). - En la lista prendas del código, cambiás los nombres, talles, precios y la ruta de la foto. - Dato clave: Si vende algo durante el día, solo cambia vendido: false por vendido: true, sube el cambio a GitHub y el botón se deshabilita automáticamente. Cómo publicarlo en GitHub Pages en 2 minutos 1. Entrá a GitHub y creá un nuevo repositorio (por ejemplo, feria-ropa) y marcalo como Público. 2. Subí el archivo index.html y la carpeta fotos. 3. Andá a Settings (Configuración) del repositorio > en el menú izquierdo seleccioná Pages. 4. En Branch, seleccioná main (o master), dejá la carpeta / (root) y hacé clic en Save. 5. Esperá 60 segundos y GitHub te va a dar el link (tipo https://tuusuario.github.io/feria-ropa). Ese es el enlace que tu amigo pone en su biografía o historias de Instagram.
