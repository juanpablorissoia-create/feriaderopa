# Catálogo de Venta de Ropa

Página estática y minimalista para venta directa de prendas por catálogo.

## Funcionamiento
- Enlace directo a WhatsApp con mensaje automático del producto seleccionado.
- Diseño mobile-first optimizado para tráfico proveniente de historias/bio de Instagram.
- Compatible con GitHub Pages sin necesidad de backend ni base de datos.

## Cómo publicar en GitHub Pages
1. Ir a **Settings** en este repositorio.
2. En la barra lateral izquierda, entrar a **Pages**.
3. En **Branch**, seleccionar `main` y la carpeta `/ (root)`.
4. Hacer clic en **Save**. En 1 minuto la página estará activa en la URL asignada.
